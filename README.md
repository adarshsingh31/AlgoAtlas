# 📖 About

**AlgoAtlas** is a modern full-stack DSA practice platform that organizes interview questions into structured learning paths instead of random lists.

The platform helps students master algorithms by tracking their progress across Dynamic Programming, Trees, Graphs, and many more topics.

Unlike traditional sheets, AlgoAtlas provides:

- 📊 Progress Tracking
- 🔐 Secure Authentication
- ☁️ Cloud Progress Sync
- 📚 Topic-wise Learning
- 🎯 Difficulty-wise Statistics
- 📈 Analytics Dashboard

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/adarshsingh31/AlgoAtlas.git
```

```bash
cd AlgoAtlas
```

---

## Install Dependencies

### Client

```bash
cd client
npm install
```

### Server

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

## Client

```env
VITE_API_URL=http://localhost:5001
VITE_GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
```

---

## Server

```env
PORT=5001

MONGODB_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY

CLIENT_URL=http://localhost:5173

GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID

GOOGLE_CLIENT_SECRET=YOUR_GOOGLE_CLIENT_SECRET
```
